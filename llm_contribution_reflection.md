# LLM Contribution Reflection

Microsoft Copilot played an important role in helping me improve and refine the algorithms and code used in this project. The LLM was used as a support tool to identify possible performance issues, suggest optimization techniques, and explain the logic behind the improvements.

## 1. Optimized Binary Tree

Copilot helped identify the limitations of a standard Binary Search Tree when it becomes unbalanced. It suggested using an AVL Tree and balancing techniques such as left and right rotations. This helped improve the worst-case search and insertion performance from O(n) to O(log n).

## 2. Optimized Task Scheduling

Copilot suggested using a priority queue instead of repeatedly sorting a list of tasks. Using a heap-based priority queue improved the efficiency of adding and removing tasks and ensured that higher-priority tasks could be executed first.

## 3. Optimized Sorting Algorithm

Copilot helped compare the performance of Bubble Sort and Merge Sort. Based on this comparison, the O(n²) Bubble Sort approach was replaced with an O(n log n) Merge Sort algorithm, making the solution more suitable for larger datasets.

## 4. Debugged Task Execution Code

Copilot assisted in identifying potential issues that could occur when a task fails during execution. It suggested using try-except blocks and logging to handle errors without stopping the entire program. This improved the stability and reliability of the task execution process.

## Reflection

The LLM was useful for generating ideas, explaining optimization techniques, and helping identify possible improvements in the code. However, I reviewed the suggestions, tested the implementations, and made sure that the final code met the requirements of the project. Using Microsoft Copilot as an assistant helped me understand the relationship between algorithm selection, time complexity, performance, and reliable software development.
